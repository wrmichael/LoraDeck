LoRaDeck

Automatic, logged FT-LoRa, FT-MESH and FT-CW contacts, chat and CW on 33 cm. By AC9HP.

  1. Connect the board's USB-C port to this computer with a data cable.
  2. Press Install LoRaDeck, pick the board's serial port (often "CP210x" or "USB to UART"), and follow the steps.
  3. Updating? When asked, leave "Erase device" unticked to keep your log and settings.
  4. When it restarts, join the Wi-Fi network LoRaDeck-XXXXXX shown on the OLED (password loradeck1) and open http://192.168.4.1.

Download your log from the LoRaDeck web page (Log tab) before installing, just in case. Ticking "Erase device" deletes the log and settings.
Cardputer: plug the Cap LoRa-1262 in with its antenna on before switching on. If the browser does not find the Cardputer, switch it off, hold the G0 button on its side while plugging in the USB cable, and press Install again. After installing, press the reset button (or switch it off and on).

From the SD card (M5Launcher): download the program .bin for the SD card, copy it onto the card, and install it with M5Launcher. Started that way LoRaDeck keeps its settings and log in Launcher's storage, and updates go the same way (a new .bin on the card), not over Wi-Fi.

Updating over Wi-Fi

A board that runs LoRaDeck already can update itself: on its web page open Settings → Update LoRaDeck and press Install latest Stable (the browser needs internet), or download the .bin here and use Install this file.

Other ways to flash

The .bin is a complete image for address 0x0. With esptool:

esptool --chip esp32s3 write-flash 0x0 loradeck-x.y.z.bin

Or open Espressif's online flasher, connect, and add the file at address 0x0.

About

LoRaDeck makes FT8-style contacts over LoRa (FT-LoRa), relays them through other stations (FT-MESH), chats in a terminal and sends real CW, all from a web page on your phone. Contacts go into an ADIF log and to your logging program.
