Station

Mode

FT-MESH: messages carry a hop count; each station repeats a message once, in relay windows after the sender's, weakest-heard first, and stays quiet when another station already repeated it. Unattended repeating is automatic control under Part 97 (§97.109, §97.205, §97.221): check the rules for your band and station. Each repeating station identifies with the CW ID.

FT-LoRa

CW (keyed carrier) and Terminal

{MY} = your call, {TO} = the other station. "<to> DE <your call>" is added to each Terminal message unless it already holds your call. CW goes out on the LoRa frequency in the quiet part of your slot; copy it with a 33 cm receiver in CW or SSB.

LoRa radio

Wi-Fi

GPS module (optional)

Heltec V3: e.g. RX 48, TX 47 (the pins Meshtastic uses), module powered from 3V3 and GND. GPS settings take effect after a restart. Clock: GPS with PPS, then internet time (NTP, when on the home network), then GPS alone, then the browser.

Update LoRaDeck

The Install latest buttons fetch the firmware from the flasher page, so this browser needs internet (the board on your home network, or a phone with mobile data). Or download loradeck-x.y.z.bin there and install the file. LoRaDeck stops transmitting, keeps its settings and log, and restarts when done; if the new version does not start properly it goes back to the old one.

Radio

Settings–Packets sent–Packets received–Received with errors–Last received–Clock–GPS–

Both stations need the same frequency, SF, bandwidth, coding rate and slot length. "Received with errors" going up while nothing is heard means a signal is there but does not decode (settings differ, or too strong at very short range: turn the power down or move the boards apart).

Console log


    
Everything LoRaDeck prints: packets sent and heard, clock changes, commands. Kept in the board's memory, about 256 KB at most; the oldest lines go first.
